# Technical and research limitations

The primary seven-state campaign has its own [model, uncertainty and failure limitations](seven_state_benchmark_report.md). It samples 40-dimensional steering/throttle sequences, uses static tire loads and dynamic first-order roll, allows forward runout recovery, and does not implement actuator-rate constraints. Two new Q03 reference means remain unresolved. K and preferred-speed/disturbance checks do not establish universal covariance superiority or real-time feasibility.

The list below describes the original vehicle milestone. The subsequent [covariance mechanism study](covariance_mechanisms.md) adds isolated estimation and parameter sweeps; its [findings](experimental_findings.md) state their additional evidence and limitations.

- This milestone studies finite-budget covariance choices in a single small deterministic prediction model. It does not establish a universal algorithm ranking.
- The 56-dimensional control sequence, single update, zero base mean, fixed covariance and finite sampling budget can produce strongly concentrated importance weights. ESS and saturation must be read alongside task success. A Gaussian density correction can be mathematically correct while still being a poor finite-sample estimator.
- Forward-only speed and a local finite horizon make final pose correction difficult after stopping at the wrong lateral offset. Replanning does not imply reliable parking or disturbance rejection. Default heading and terminal costs are task design choices.
- Matching normalized trace does not match determinant, physical units, induced state spread, saturation or post-clipping exploration. Only one correlation sign/magnitude and one normalized trace are compared.
- The common fixed base isolates the proposal's finite-budget effect. Results would change under a covariance-dependent base, cost-only weighting, temporal correlation, multiple inner iterations, or different costs.
- A kinematic bicycle has no tire force, slip angle, actuator lag, friction uncertainty, dynamic contact or legged locomotion. DIAL's original setting cannot be reproduced by this toy model. No state estimator or observation noise model is present.
- Collision geometry is a disk against circles. Segment sweeps follow Euler position interpolation and conservatively include an execution impulse's displacement; obstacle proximity remains a discretely sampled soft cost. There is no certified collision avoidance or continuous curved-body swept geometry.
- Only fixed-time impulses and additive independent Gaussian execution noise are supported. Model mismatch is parameterized through execution wheelbase and actuator gains; no disturbance forecast or robust tracker is available to the controller.
- The obstacle field and model mismatch scenarios are implemented and covered by short execution tests. The principal comparison is open space, narrow passage and disturbance; isolated mismatch smoke runs do not establish sensitivity curves.
- Five seeds yield exploratory descriptive statistics. Some metrics are conditioned on success or observed recovery and have fewer observations. Binary proportions use Wilson intervals; continuous means and paired differences use descriptive Student-t intervals with only five seeds. No hypothesis testing or power analysis has been performed.
- Timing is hardware/load dependent and sequential controller order can confound latency. Wall-clock mode calibrates batch medians, reports misses and does not enforce a hard deadline. Process lifetime peak RSS cannot distinguish per-controller memory use.
- GPU backends are not implemented. The controller interface permits later backends, but NumPy-specific internals will require a backend implementation. GIF output works headlessly; MP4 export is not implemented.
- Large visual archives/animations remain local. Reproduction from Git regenerates them; stored YAML/CSV/JSON reconstruct numerical evidence. The plotted sample subset is unweighted and should not be read as the complete optimized distribution.

Further work should follow the [mathematical investigation plan](research_questions.md): derive each mechanism, verify it on an isolated numerical problem, and select a control example that makes its characteristic behavior observable. Implementation and evidence for the planned families remain outstanding. Shared vehicle performance tables alone cannot complete that investigation.
